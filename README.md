# Correlation-Coefficient-and-Scatter-Plots
It automatically generates correlation coefficients and scatter plots.

# 相関分析＆散布図 自動分析　マニュアル

本ツールは、教育現場や心理学の研究において、データの相関関係を直感的に分析・視覚化し、**そのまま論文やレポートに使える形（APA形式）** で出力するための専用Webアプリケーションです。

---

## 1. 事前準備：データ作成のチェックリスト

本ツールは **CSVファイル（カンマ区切り）** のみを読み込みます。分析をスムーズに進めるためのチェックリストです。

- [ ] **1行目は変数名になっているか**（例：学習時間, テスト得点, 不安感）
- [ ] **2行目以降は半角数値データになっているか**
- [ ] **欠損値は「空欄」になっているか**（欠席などでデータがないセルは、0やNAと入力せず、完全に空欄にしてください。ツールが自動でペアワイズ削除します）
- [ ] **保存形式はCSVか**（Excelの場合：「ファイル」>「名前を付けて保存」> ファイルの種類を「CSV (コンマ区切り) (*.csv)」に変更して保存）

---

## 2. ツールの基本的な使い方（3ステップ）

### Step 1: データファイルの読み込み
1. ダウンロードした `index.html` をダブルクリックし、ブラウザ（ChromeやEdgeなど）で開きます。
2. 画面上の「ここにCSVファイルをドラッグ＆ドロップ」という枠内に、先ほど作成したCSVファイルをドラッグ＆ドロップします。
3. 読み込みに成功すると、枠が緑色に変わりファイル名が表示されます。

### Step 2: 分析変数の選択
1. 読み込みが完了すると、「2. 分析変数の選択」というカードが出現します。
2. データ内の変数がチェックボックスとして表示されるので、**分析したい変数を2つ以上**選択してください。
3. 「分析を実行する」ボタンをクリックします。

### Step 3: 結果の確認とコピー
画面下部に3つの結果が出力されます。

1. **相関行列（APA形式）**
   - 論文にそのまま使える形式の表が表示されます。
   - 「📋 コピー」ボタンを押すと、Word等に貼り付け可能なテキストがコピーされます。
2. **Web用散布図**
   - ブラウザ上でデータの散らばりや外れ値をサクッと確認できます。
3. **JASP R Console用 再現コード**
   - 統計ソフト「JASP」と連携させ、論文用の高品質な画像を出力するためのコードです。

---

## 3. 論文執筆のための「本質的な」結果の読み方

単に数字を書き写すのではなく、統計的意味を理解して論文を執筆しましょう。

### ① 手法の違いと記号の意味
* **(P) Pearson（ピアソン）の積率相関係数**：データが正規分布（左右対称な山の形）の場合に適用。
* **(S) Spearman（スピアマン）の順位相関係数**：データに偏りがある、または外れ値がある場合に適用（本ツールはJarque-Bera検定で自動判定・適用します）。

### ② アスタリスク（有意水準）の罠
* `*` : p < .05 （統計的に有意な相関あり）
* `**` : p < .01 （強い有意性）
* `***`: p < .001 （非常に強い有意性）
* 💡 **【見落としやすい点】**：初心者は「星が多い＝相関が強い」と誤解しがちです。星（p値）は「相関がゼロではない確率の高さ」に過ぎません。**相関の強さは必ず「係数自体の大きさ（0〜1）」で判断**してください（目安：0.2=弱い、0.4=中程度、0.7=強い）。

### 📝 論文執筆のテンプレート（APA形式）
> **【執筆例】**
> 本研究で測定した各変数間の記述統計および相関行列をTable 1に示す。Jarque-Bera検定によりデータの正規性を確認した結果、一部の変数において正規性が棄却されたため、該当する変数のペアについてはSpearmanの順位相関係数（ρ）を算出した。その他の変数についてはPearsonの積率相関係数（r）を算出した。
> 
> 分析の結果、「学習時間」と「テスト得点」の間に有意な正の相関が認められた（$r = .45, p < .01$）。これは、学習時間が長い生徒ほどテストの得点が高い傾向にあることを示している。一方で、「学習時間」と「不安感」の間には有意な相関は認められなかった（$
ho = -.08, n.s.$）。

## 4. JASP連携による高品質な図の作成とトラブルシューティング

本ツールの出力結果の一番下にある「Rコード」を使うと、JASPから直接**「散布図行列（相関係数と回帰線付きのグラフ）」**を自動生成・保存できます。

### 実行手順
1. JASPを起動し、右上の「＋」ボタンから「R (Beta)」モジュールをオンにします。
2. メニューの「R」アイコンから「R Console」を開きます。
3. 本ツールでコピーしたコードを左側の枠に貼り付け、「Run Code（またはCtrl+Enter）」を押します。
4. **お使いのパソコンの「ダウンロード」フォルダ**に、実行日時のついた画像ファイル（例：`scatter_matrix_20260818_175000.png`）が自動保存されます。

### 🚨 トラブルシューティング（なぜJASPに直接図を出さないのか？）
* **疑問**：「実行してもJASPの画面にグラフが出ないのですが？」
* **回答**：**意図的な安全設計**です。JASP上でRの図を直接描画しようとすると、OSのウィンドウ管理と衝突し、**JASP自体がクラッシュ（強制終了）して分析データが消滅するリスク**があります。
* 本ツールは、この悲劇を防ぐため、画面への出力をバイパスし、OSが書き込みを絶対許可する「ダウンロードフォルダ」へ直接画像ファイルとして書き出すプロ仕様の設計を行っています。安心してお使いください。
